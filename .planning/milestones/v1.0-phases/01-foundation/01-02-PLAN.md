    - Test: make_store_id("linear") produces [u8; 16] that is not all zeros
    - Test: make_store_id("linear") called twice produces identical result (deterministic)
    - Test: make_store_id("linear") != make_store_id("gmail") (unique per app)
  </behavior>
  <action>
    1. Create `src-tauri/src/routing.rs`:
       - `pub fn extract_base_domain(url: &str) -> String` -- parse URL, extract registrable domain (handle two-part TLDs like botto.is by taking last 2 segments; for common TLDs like .com/.org/.net take last 2 segments). Use a simple heuristic: split host by '.', if >= 2 parts take last 2. This covers 99% of cases for Phase 1.
       - `pub fn is_subdomain_of(candidate: &str, base: &str) -> bool` -- candidate ends with ".{base}" (not just base itself)
       - `pub fn is_oauth_provider(url: &str) -> bool` -- check URL host against known OAuth domains: accounts.google.com, login.microsoftonline.com, github.com/login, auth0.com, okta.com, appleid.apple.com
       - `pub fn make_store_id(app_id: &str) -> [u8; 16]` -- `md5::compute(app_id.as_bytes()).0`
       - `#[cfg(test)] mod tests` with all behavior tests above

    2. Create `src-tauri/src/commands/webview.rs`:
       - `#[tauri::command] pub fn switch_app(app_id: String, state: State<'_, Mutex<AppState>>, app_handle: AppHandle) -> Result<(), String>`
         - Lock state, check if webview already created via `state.webviews_created`
         - If NOT created: build new WebviewWindow:
           - label: `format!("app-{}", app_id)`
           - URL: look up app_id in state.config.apps to get URL
           - `.data_store_identifier(make_store_id(&app_id))` for session isolation
           - `.visible(true)` for the new webview
           - Set `on_navigation` closure: extract base domain from app URL, allow same domain + subdomains + OAuth providers, block (return false) everything else. When blocking, call `app_handle.opener().open_url()` to open in system browser. NOTE: The on_navigation closure cannot easily call opener (no app_handle access inside). Instead, return false and handle external opening via a separate mechanism, OR clone the app_handle into the closure.
           - Set `on_new_window` closure: same domain logic. For external non-OAuth: call opener then return Deny.
           - Add app_id to `state.webviews_created`
         - If already created: get existing window via `app_handle.get_webview_window(&label)`, call `.show()`
         - Hide the previously active webview (if any): get previous label from `state.active_app_id`, call `.hide()`
         - Update `state.active_app_id = Some(app_id)`

    3. Update `src-tauri/src/commands/mod.rs` to add `pub mod webview;`

    4. Update `src-tauri/src/lib.rs`:
       - Add `mod routing;`
       - Register `commands::webview::switch_app` in `generate_handler!`

    5. Update `src-tauri/src/state.rs` if needed (should already have webviews_created HashSet from Plan 01).

    CRITICAL per RESEARCH.md:
    - Use `data_store_identifier` NOT `data_directory` -- macOS WKWebView requires this
    - NEVER pass `[0; 16]` -- always derive from app_id via md5
    - Set BOTH `on_navigation` AND `on_new_window` on every webview
    - Check webview existence before creating (prevent label collision crash)
    - WebviewWindows are separate OS windows -- hide/show is the switching mechanism
  </action>
