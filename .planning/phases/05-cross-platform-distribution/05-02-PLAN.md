<task type="auto">
  <name>Task 2: UpdateBanner component and integration in App.tsx</name>
  <files>src/components/UpdateBanner.tsx, src/App.tsx</files>
  <action>
**Create src/components/UpdateBanner.tsx:**

A React component that:
1. On mount, calls `check()` from `@tauri-apps/plugin-updater` inside a try/catch (silent fail).
2. If `update?.available`, stores `update.version` in state and shows the banner.
3. Banner is positioned fixed at the bottom of the viewport, matching the monochromatic Arc aesthetic (bg-[#1a1a22] or similar dark tone, subtle border-t, small text).
4. Shows: "Update available (v{version})" with a "Restart" button and a dismiss "x" button.
5. Clicking "Restart": sets a loading state, calls `check()` again, then `update.downloadAndInstall()`, then `relaunch()` from `@tauri-apps/plugin-process`. Wrap in try/catch — on error, show nothing (silent fail per user decision).
6. Clicking dismiss: hides the banner (local state, banner stays hidden for session).
7. The entire check is non-blocking — the app renders normally while check() runs.

Style: Tailwind classes, dark theme consistent with sidebar (#111117 background area). Small, unobtrusive. Example layout:
```
[fixed bottom-0 left-0 right-0 h-8 bg-[#1a1a22] border-t border-white/5 flex items-center justify-between px-4 text-xs text-white/60]
  <span>Update available (v0.2.0)</span>
  <div class="flex gap-2">
    <button class="text-blue-400 hover:text-blue-300">Restart</button>
    <button class="text-white/40 hover:text-white/60">x</button>
  </div>
```

**Update src/App.tsx:**
Import and render `<UpdateBanner />` at the bottom of the component tree (after the main layout). It renders itself fixed-position so it overlays without affecting layout.

Important: The updater check will fail in dev mode (no update manifest available) — this is expected. The component should handle this gracefully (silent catch, no banner shown).
