2. In `src-tauri/capabilities/default.json`, add permissions:
   ```json
   "global-shortcut:allow-register",
   "global-shortcut:allow-is-registered",
   "global-shortcut:allow-unregister"
   ```

3. In `lib.rs`, add the global shortcut plugin with handler. Place BEFORE `.invoke_handler()` in the builder chain:

   ```rust
   use tauri::Emitter;
   use tauri_plugin_global_shortcut::{Code, GlobalShortcutExt, Modifiers, Shortcut, ShortcutState};
   ```

   In setup(), after managing AppState:

   **Plugin init with handler:**
   ```rust
   let app_handle_sc = app.handle().clone();
   app.handle().plugin(
       tauri_plugin_global_shortcut::Builder::new()
           .with_handler(move |_app, shortcut, event| {
               if event.state() != ShortcutState::Pressed {
                   return; // CRITICAL: filter out Released events
               }
               // Cmd+B -> emit sidebar-toggle to frontend
               if shortcut == &Shortcut::new(Some(Modifiers::SUPER), Code::KeyB) {
                   app_handle_sc.emit("sidebar-toggle", ()).ok();
                   return;
               }
               // Cmd+R -> reload active webview
               if shortcut == &Shortcut::new(Some(Modifiers::SUPER), Code::KeyR) {
                   let state = app_handle_sc.state::<std::sync::Mutex<crate::state::AppState>>();
                   if let Ok(st) = state.lock() {
                       if let Some(ref app_id) = st.active_app_id {
                           let label = format!("app-{}", app_id);
                           if let Some(wv) = app_handle_sc.get_webview_window(&label) {
                               let _ = wv.eval("location.reload()");
                           }
                       }
                   }
                   return;
               }
               // Cmd+1 through Cmd+9 -> switch to app by position
               let digit_codes = [
                   Code::Digit1, Code::Digit2, Code::Digit3,
                   Code::Digit4, Code::Digit5, Code::Digit6,
                   Code::Digit7, Code::Digit8, Code::Digit9,
               ];
               if let Some(pos) = digit_codes.iter().position(|c| *c == shortcut.key) {
                   if shortcut.mods == Some(Modifiers::SUPER) {
                       let state = app_handle_sc.state::<std::sync::Mutex<crate::state::AppState>>();
                       let app_id = {
                           let locked = match state.lock() {
                               Ok(l) => l,
                               Err(_) => return,
                           };
                           locked.config.apps.get(pos).map(|a| a.id.clone())
                       };
                       if let Some(id) = app_id {
                           let _ = crate::commands::webview::switch_app_impl(id, &app_handle_sc, &state);
                       }
                   }
               }
           })
           .build(),
   )?;
   ```

   **Register all shortcuts (after plugin init, still in setup):**
   ```rust
   let digit_codes = [
       Code::Digit1, Code::Digit2, Code::Digit3,
       Code::Digit4, Code::Digit5, Code::Digit6,
       Code::Digit7, Code::Digit8, Code::Digit9,
   ];
   for code in digit_codes {
       app.global_shortcut().register(Shortcut::new(Some(Modifiers::SUPER), code))?;
   }
   app.global_shortcut().register(Shortcut::new(Some(Modifiers::SUPER), Code::KeyB))?;
   app.global_shortcut().register(Shortcut::new(Some(Modifiers::SUPER), Code::KeyR))?;
   ```

   Use `Modifiers::SUPER` for Cmd on macOS (NOT `Modifiers::CONTROL`). This is a locked architectural decision.

   NOTE: The shortcut comparison may need to use field matching (`shortcut.key == Code::KeyB && shortcut.mods == Some(Modifiers::SUPER)`) instead of `==` with `Shortcut::new()` if PartialEq is not implemented for reference comparison. Test and adjust.

<task type="auto">
  <name>Task 2: Wire sidebar-toggle listener, lastActiveAppId persistence, and startup restore in React</name>
  <files>src/hooks/useAppsConfig.ts</files>
  <action>
1. Extend `useAppsConfig` hook to:

   **Listen for sidebar-toggle event:**
   - Import `listen` from `@tauri-apps/api/event`
   - In a useEffect, set up listener for `"sidebar-toggle"` event
   - On event: toggle `sidebarCollapsed` state, persist via `invoke("save_config", { config: updatedConfig })`
   - Return the unlisten function in cleanup
   - Expose `sidebarCollapsed` and `setSidebarCollapsed` in the hook return

   **Persist lastActiveAppId on switch:**
   - In `switchApp`, after setting activeAppId, also update config.lastActiveAppId and call `invoke("save_config", { config: updatedConfig })`
   - This way every app switch persists the last active app

   **Restore last active app on startup:**
   - After loading config in `init()`, check `config.lastActiveAppId`
   - If it exists AND the app ID is still in `config.apps`, call `switchApp(config.lastActiveAppId)` to auto-load
   - If the app no longer exists in config, ignore (show empty state)

   **Updated return type:**
   ```typescript
   interface UseAppsConfigResult {
     config: NexusConfig | null;
     activeAppId: string | null;
     sidebarCollapsed: boolean;
     switchApp: (id: string) => Promise<void>;
     loading: boolean;
   }
   ```

   **Emit active app change to Rust (for Cmd+1-9 accuracy):**
   The shortcut handler in Rust reads `active_app_id` from AppState. When React calls `switch_app` IPC, the Rust side already updates `active_app_id`. No extra work needed.

   **Emit sidebar-toggle from Cmd+1-9 switch:**
   When Cmd+1-9 fires, it calls `switch_app_impl` in Rust which shows/hides webviews. But React also needs to know the new activeAppId. Two approaches:
   - Option A: Rust emits an `"app-switched"` event with the new app_id, React listens
   - Option B: React polls `load_config` after shortcut

   Use Option A: In `switch_app_impl` (in webview.rs), after updating `active_app_id`, emit `"app-switched"` event with the app_id payload. Add a listener in `useAppsConfig` for `"app-switched"` that updates `activeAppId` state.

   This requires a small addition to `src-tauri/src/commands/webview.rs`:
   ```rust
   // At the end of switch_app_impl, after setting active_app_id:
   let _ = app_handle.emit("app-switched", &app_id);
   ```

2. Update `App.tsx` to receive `sidebarCollapsed` from the hook instead of managing it separately.

IMPORTANT: The sidebar-toggle listener and save_config call must handle the race condition where multiple rapid Cmd+B presses could interleave. Use a functional setState (`prev => !prev`) and only call save_config after state update via useEffect.
